# Подготовка доказательств для курсовой

Проект запускается командой `bash start_git_bash.sh` из Git Bash. Рабочая база находится в `instance/sportmeet.sqlite3`. Перед демонстрацией сделайте копию этого файла при остановленном сервере. Снимки ниже должны быть сделаны в настоящем браузере с запущенным приложением; таблицы и изображения из пояснительной записки не заменяют их.

## Семь снимков интерфейса

Создайте отдельные учебные аккаунты организатора и участника через сайт, а администраторов через `.venv/Scripts/python.exe -m flask --app app create-user`. Используйте собственные тестовые адреса без личных данных других людей. Для T2 задайте дату через несколько дней, чтобы заявка не устарела при проверке.

| Протокол | Действие в приложении | Что должно быть видно на снимке |
|---|---|---|
| T1 | Гость открывает `/venues`, вводит поиск или выбирает район. | Фильтр и найденные площадки. |
| T2 | Организатор создаёт тренировку и открывает «Мои мероприятия». | Заголовок новой тренировки и состояние «На проверке у администратора». |
| T3 | Администратор тренировок открывает `/admin` и публикует заявку. | Занятие в разделе «Опубликованные тренировки»; при необходимости дополнительно откройте публичную карточку. |
| T4 | Участник открывает опубликованную тренировку, подаёт заявку и заходит в «Мои заявки». | Статус «Ожидает ответа организатора»; свободное место ещё не занято. |
| T5 | Организатор открывает «Мои мероприятия» → «Заявки» и подтверждает заявку. | Имя участника и статус «Участие подтверждено». |
| T6 | Участник обновляет «Мои заявки», затем при необходимости отменяет участие. | Сначала «Подтверждена организатором», после отмены — «Отменена». |
| T7 | Участник отправляет отдельное сообщение об ошибке площадки. Администратор площадок открывает `/admin` и отмечает его как решённое либо передаёт глобальному администратору. | Очередь обращений, затем итоговый статус `resolved` или `escalated`; это не заявка на тренировку. Для одного протокола можно сделать составной снимок «до/после» из собственных фактических кадров. |

Вставьте семь фактических снимков в приложение А редактируемой записки рядом с соответствующими протоколами. Для каждого укажите дату, браузер и страницу. После вставки обновите содержание и проверьте итоговый PDF: допустимый объём одновременно по двум присланным документам — 35–50 страниц. При необходимости уменьшайте изображение или убирайте пустые места в приложении: текущая записка уже занимает 44 страницы. Не публикуйте в кадре пароль и почту реального человека.

## Ресурсы на компьютере защиты

Записка содержит времена семи локальных GET-запросов, оценку времени SQL и размер комплектной рабочей БД. Для полноты таблицы метрик измерьте отдельно на своём Windows-компьютере:

1. В DevTools браузера, вкладка «Сеть», очистите список, выполните каждый процесс и запишите входящий и исходящий объём с учётом перехода после POST и загрузки CSS. Запишите версию браузера и условия сети.
2. В диспетчере задач браузера запишите память вкладки приложения до и после серии действий. Отдельно в диспетчере задач Windows зафиксируйте память процесса Python, обслуживающего Flask. Укажите конкретное имя показателя и единицу измерения.
3. Для диска сервера запишите размер `instance/sportmeet.sqlite3` и используемого окружения проекта. Дисковое пространство клиента измеряйте на новом отдельном профиле браузера до и после загрузки страниц; размер всего профиля включает служебные данные браузера и должен так и называться.

Не смешивайте измерения Windows и Linux в одной строке таблицы. Строки в записке, где явно сказано «не измерено», заменяйте фактическими результатами только после их фиксации. Проверка оригинальности и показатель ИИ определяются системой вуза и не следуют из локальных тестов.

## Сверка перед отправкой

- Заполните титульный лист: кафедра, факультет, ФИО, группа, проверяющий, дата.
- Проверьте название темы и данные преподавателя по своему индивидуальному заданию.
- Просмотрите все страницы PDF после добавления снимков; обновите номера страниц в содержании.
- Дополните добровольный журнал ИИ полным списком реально использованных запросов, названиями и версиями моделей и доступными метриками. Недоступные точные счётчики токенов нельзя выдумывать.
- Архив проекта содержит единственную комплектную рабочую базу `instance/sportmeet.sqlite3`, исходный код и исходную выгрузку. Для воспроизведения на другом компьютере запустите `bash start_git_bash.sh`.
