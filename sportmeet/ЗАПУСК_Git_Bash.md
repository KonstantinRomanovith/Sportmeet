# Запуск «СпортРядом» в Git Bash (Windows)

1. Остановите прежний сервер клавишами **Ctrl+C**. Распакуйте новый архив **в отдельную папку**, чтобы старые файлы `instance/` не смешались с комплектной базой.
2. Откройте папку `sportmeet` в Проводнике и выберите «Open Git Bash here». Рядом со скриптом `start_git_bash.sh` должна находиться основная база `instance/sportmeet.sqlite3`.
3. Выполните:

   ```bash
   bash start_git_bash.sh
   ```

   При первом запуске скрипт создаст `.venv` и установит зависимости. База уже заполнена: 4751 площадка, 30 пользователей и 36 встреч, из которых 29 будущих доступны для записи. Отдельную базу копировать или вручную заполнять не требуется.
4. После строки `Running on http://127.0.0.1:5000` откройте адрес в браузере. Логины указаны в [УЧЁТНЫЕ_ЗАПИСИ.md](УЧЁТНЫЕ_ЗАПИСИ.md); общий пароль `SportRyadom26!`. Сервер работает, пока это окно Git Bash открыто.

Все заявки, новые встречи и исправления карточек сохраняются в **этом же** файле `instance/sportmeet.sqlite3`. Повторный запуск не сбрасывает изменения. Для создания дополнительного администратора можно открыть второе окно Git Bash и выполнить:

```bash
.venv/Scripts/python.exe -m flask --app app create-user
```

## Обновление после начала собственной работы

Если вы уже создали нужные вам аккаунты или мероприятия, остановите сервер и сохраните копию `instance/sportmeet.sqlite3`. Чтобы продолжить с ними в новой версии, замените комплектную базу нового архива вашей сохранённой базой перед запуском. Сейчас, пока вы только проверяете готовую версию, используйте комплектную базу нового архива.

## Если запуск не работает

| Сообщение | Что делать |
|---|---|
| `Не найдена основная база instance/sportmeet.sqlite3` | Распакуйте архив полностью в новую папку; не запускайте отдельный скопированный скрипт. |
| `python: command not found` или открывается Microsoft Store | Скрипт сначала пробует `py -3`; установите Python 3.11+ с опцией `Add python.exe to PATH` и заново откройте Git Bash. |
| `No module named venv` | Переустановите Python с поддержкой `venv`, удалите неполную `.venv` и повторите запуск. |
| Ошибка `pip` или сети | При первой установке зависимостей нужен интернет. |
| `No time zone found with key Europe/Moscow` | Выполните `.venv/Scripts/python.exe -m pip install tzdata` и перезапустите скрипт. |
| `Address already in use` | Остановите ранее запущенный сервер на порту 5000. |
| «Неверные данные для входа» | Проверьте адрес и пароль из [УЧЁТНЫЕ_ЗАПИСИ.md](УЧЁТНЫЕ_ЗАПИСИ.md) и убедитесь, что запущен сервер из новой папки. |

Не отправляйте пароль от своих дополнительных учётных записей при обращении за помощью.
